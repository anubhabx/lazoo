were never initialized, so neither fixture could connect to a server.

## Schema boundary

Current official Codex sources define a stdio MCP entry in
`[mcp_servers.<name>]` with `command` and `args`; `enabled` defaults to true
and `enabled = false` disables initialization. The existing selected-config
writer uses those reviewed stdio fields and the reviewed URL field. See
[MCP config types](https://github.com/openai/codex/blob/main/codex-rs/config/src/mcp_types.rs)
and [MCP CLI arguments](https://github.com/openai/codex/blob/main/codex-rs/cli/src/mcp_cmd.rs).
